# Ecoboni

Modelo independente de oferta, com conteúdo ilustrativo. Sem vínculo oficial com o anunciante.

## Abrir

Abra index.html no navegador ou execute `node serve.cjs` e visite http://127.0.0.1:4173. Não exige instalação de dependências nem build.

## Arquivos

- index.html: site do modelo
- style.css: estilos responsivos
- app.js: menu, filtros e interações locais
- revisao.html: referências e registro de revisão

## Limites

Formulários não enviam nem armazenam dados. WhatsApp, CMS, identidade definitiva e conteúdo aprovado precisam de configuração. Fotos ilustrativas carregadas do Unsplash.
